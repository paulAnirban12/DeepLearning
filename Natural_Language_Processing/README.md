# Natural Language Processing Portfolio

This folder contains natural language processing projects that cover both foundational and modern NLP methods. The work includes recurrent neural network based text classification, transformer-based Named Entity Recognition, and NLP pipelines using tokenization, TF-IDF, prompt classification, semantic embeddings, and similarity-based methods.

---

## 1. Text Classifiers

**Folder:** `Text_Classifiers/`

### Project Summary
This subfolder contains two notebook projects focused on NLP model implementation:

- a **GRU-based text classification model** trained on the IMDB movie reviews dataset
- a **BERT-based Named Entity Recognition model** fine-tuned on the CoNLL-2003 dataset

### Concepts Demonstrated
- text preprocessing
- vocabulary construction
- sequence padding and truncation
- recurrent neural networks
- pretrained transformer fine-tuning
- token classification
- model evaluation on NLP tasks

### Learning Objective
To understand the difference between recurrent and transformer-based approaches for text understanding and classification.

---

## 2. NLP Pipeline and LLM Concepts

**Folder:** `NLP-Pipeline-LLM-Concepts/`

### Project Summary
This subfolder contains a notebook demonstrating a compact NLP pipeline that combines tokenization, TF-IDF based classification, prompt classification, semantic embeddings, and cosine similarity.

### Concepts Demonstrated
- Hugging Face tokenization
- TF-IDF vectorization
- Logistic Regression for text classification
- semantic embedding generation
- text similarity analysis
- integrating classical NLP techniques with modern embedding-based methods

### Learning Objective
To demonstrate how multiple NLP components can be combined into a practical pipeline for text classification and semantic understanding.

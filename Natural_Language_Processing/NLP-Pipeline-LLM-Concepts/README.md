# NLP Pipeline and LLM Concepts Portfolio

This folder contains notebook work focused on natural language processing pipelines and LLM-related concepts. The project demonstrates how tokenization, text classification, semantic embeddings, and similarity-based methods can be combined in a single workflow for text understanding tasks.

---

## 1. NLP Pipeline with Tokenization, Prompt Classification, and Semantic Embeddings

**File:** `NLP_Pipeline_with_Tokenization__Prompt_Classification_and_Semantic_Embeddings.ipynb`

### Project Summary
This notebook demonstrates a compact NLP pipeline that combines both classical and modern methods for text processing and classification. It includes tokenization with a pretrained Hugging Face tokenizer, TF-IDF based feature extraction, prompt classification using Logistic Regression, and semantic embedding generation using Sentence Transformers.

### Concepts Demonstrated
- text tokenization
- TF-IDF vectorization
- prompt classification
- semantic embedding generation
- cosine similarity based comparison
- integrating classical ML with modern NLP tools

### Learning Objective
To understand how different NLP components can be combined into a practical text processing and classification pipeline.

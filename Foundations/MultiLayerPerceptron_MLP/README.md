# MultiLayer Perceptron (MLP) Projects Portfolio

This folder contains deep learning notebooks focused on MultiLayer Perceptron models for image classification. These projects demonstrate foundational neural network concepts such as fully connected layers, forward propagation, training, and evaluation on image datasets.

---

## 1. Building and Training an MLP on the MNIST Dataset

**File:** `Building_and_Training_an_MLP_on_the_MNIST_Dataset.ipynb`

### Project Summary
This notebook implements a MultiLayer Perceptron model for handwritten digit classification using the MNIST dataset. The notebook demonstrates how image pixels can be flattened and passed through fully connected neural network layers for classification.

### Skills Demonstrated
- building a feedforward neural network
- preprocessing image data
- flattening image inputs
- training and evaluation using deep learning frameworks
- multiclass classification

### Dataset
- MNIST handwritten digit dataset

### Objective
To understand the working of MLPs on a standard image classification benchmark.

---

## 2. MLP for Classifying Image Dataset of Symbols

**File:** `MLP_for_classifying_Image_dataset_of_Symbols.ipynb`

### Project Summary
This notebook applies a MultiLayer Perceptron model to classify images of symbols. It demonstrates how MLPs can be used on custom or structured image datasets where the input is converted into vector form before classification.

### Skills Demonstrated
- custom dataset classification
- image preprocessing
- MLP architecture design
- training and model evaluation
- applying neural networks to symbol recognition

### Objective
To demonstrate how a simple MLP can be adapted to classify non-digit image datasets.

# Foundations Portfolio

This folder contains foundational deep learning work focused on core neural network concepts. The projects here are useful for building intuition about basic architectures, training behavior, and mathematical operations that support more advanced deep learning models.

---

## 1. MultiLayer Perceptron (MLP) Projects

**Folder:** `MultiLayerPerceptron_MLP/`

### Project Summary
This subfolder contains notebook projects that implement MultiLayer Perceptron models for image classification tasks. These projects demonstrate how fully connected neural networks can be trained on datasets such as MNIST and symbol image datasets.

### Concepts Demonstrated
- feedforward neural networks
- image preprocessing
- flattening input features
- training and evaluation
- multiclass classification

### Learning Objective
To understand the structure and training of basic fully connected neural networks.

---

## 2. Batch Normalization Forward Pass

**File:** `batch_normalization_forward_pass.py`

### Project Summary
This script manually implements the forward pass of batch normalization and compares the output with PyTorch’s built-in `BatchNorm1d` layer.

### Concepts Demonstrated
- batch mean calculation
- variance calculation
- input normalization
- applying scale and shift parameters
- validating manual implementation against PyTorch

### Learning Objective
To build intuition for how batch normalization works internally at the mathematical level.

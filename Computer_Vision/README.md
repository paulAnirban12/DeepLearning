## 1. CNN on CIFAR-10 from Scratch

**File:** `cnn_cifar10_from_scratch_pytorch.ipynb`

### Project Summary
This notebook implements a Convolutional Neural Network from scratch using PyTorch for classifying images from the CIFAR-10 dataset.

### Skills Demonstrated
- PyTorch model building
- convolution and pooling layers
- training and evaluation pipeline
- image classification
- performance monitoring

### Dataset
- CIFAR-10

### Objective
To understand how CNNs work by building and training a custom model without transfer learning.

---

## 2. VGG16 Feature Extraction on CIFAR-10

**File:** `vgg16_feature_extraction_cifar10.ipynb`

### Project Summary
This notebook applies transfer learning using a pretrained VGG16 model for CIFAR-10 classification. The convolutional feature extractor is reused while the final classifier is adapted to the target dataset.

### Skills Demonstrated
- transfer learning
- feature extraction
- working with pretrained models
- fine-tuning the classifier layer
- evaluation on image classification tasks

### Dataset
- CIFAR-10

### Objective
To demonstrate how pretrained CNN models can improve performance and reduce training complexity.

---

## 3. Deep Learning for Image Captioning

**File:** `Deep_Learning_for_Image_Captioning.ipynb`

### Project Summary
This notebook explores an image captioning pipeline that combines visual feature extraction with text generation techniques to produce descriptions for images.

### Skills Demonstrated
- combining computer vision and NLP
- image feature extraction
- caption preprocessing
- sequence modeling for text generation
- multimodal deep learning concepts

### Objective
To understand how image and language models can be integrated for caption generation tasks.

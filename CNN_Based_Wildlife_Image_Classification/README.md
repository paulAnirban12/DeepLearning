# CNN Based Wildlife Image Classification

## Project Overview

This project implements a Convolutional Neural Network (CNN) to classify wildlife images into different categories. It demonstrates the full deep learning workflow, including data preprocessing, model training, evaluation, and visualization of results.

---

## Files and Description

### Main Notebook
- **CNN_Based_Wildlife_Image_Classification.ipynb**
  - contains data preprocessing, model architecture, training, evaluation, and prediction steps

### Visual Outputs

- **Accuracy.png**
  - shows training and validation accuracy trends

- **BAR_CHART.png**
  - compares model performance visually

- **Confusion_Matrix.png**
  - shows classification correctness and errors across classes

- **Classification_Report.png**
  - displays precision, recall, and F1-score

- **classification_report_visual.png**
  - visual representation of classification metrics

- **Test Output.png**
  - sample predictions on unseen test images

- **final_model_comparison_table.jpg**
  - summary table comparing model performance

---

- image preprocessing and dataset preparation

- evaluation using:
